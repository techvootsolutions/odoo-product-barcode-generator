Feature Details

Configurations

Configure global barcode settings, sequence rules, and default barcode encoding formats under Inventory > Configuration > Settings.

Barcode Security Rights

Assign 'Generate Barcode' user permissions under Settings > Users to restrict generation access to authorized inventory managers.

Barcode Sequences

Define custom sequence prefixes, padding lengths, and next number increments under Technical > Sequences.

Product Template Form & Action

Click the 'Generate Barcode' button on any product form to instantly compute and assign a unique barcode value.

Bulk Barcode Generation Wizard

Select multiple untagged products in the Product list view, open Action > Generate Barcode, and click to process in bulk.

Barcode Image Rendering & Preview

Rendered barcode images appear directly on the product form ready for on-screen scanning or print label outputs.

Frequently Asked Questions

Common questions about installation, compatibility, and features

Does Odoo generate barcodes automatically by default?
No. Standard Odoo requires manual barcode entry for each product. This module fills that gap by providing automatic sequence-based barcode generation.
Which Odoo versions are supported?
Built for Odoo 19 Community Edition, Enterprise Edition, and Odoo.sh deployments.
Can I generate barcodes in bulk for multiple products?
Yes. Select multiple products in the list view, open Action > Generate Barcode, and click to execute bulk barcode generation instantly.
Which barcode formats are supported?
Supports Code128, EAN13, and custom numeric sequence formats configurable under Inventory Settings.
How does role-based access control work?
Security access groups restrict barcode generation buttons and configuration access only to authorized inventory managers.
Can I preview the rendered barcode image on the product form?
Yes. Rendered barcode images are previewed directly on product template views ready for verification and label printing.
How do I request customization?
